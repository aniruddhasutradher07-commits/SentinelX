# 🔥 Extreme Heatwave Early Warning & Human Thermal Stress System

Backend API for a Smart India Hackathon 2026 solution focused on detecting extreme heatwave conditions and assessing human thermal stress at ward level.

## 🎯 Problem

Extreme heat is affected not only by temperature, but also by humidity, wind, solar radiation and local vulnerability.

Traditional temperature-only warnings may not accurately represent the actual thermal stress experienced by people.

## 💡 Solution

This backend provides APIs for:

- Weather data management
- Ward-level data management
- UTCI and WBGT thermal-stress input
- Heat-risk calculation
- Vulnerability-based risk scoring
- Risk prediction storage
- Automatic heat alerts
- Dashboard data aggregation

Weather Data
     ↓
UTCI / WBGT
