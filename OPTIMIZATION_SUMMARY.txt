7. TROUBLESHOOTING
================================================================================

Build fails with "module not found":
  → Check .dockerignore is not excluding needed files
  → Verify all COPY paths are correct
  → Run locally first: python -m pip install -r requirements.txt

Container exits immediately:
  → Check logs: docker logs sentinelx_backend
  → Verify .env file has correct API keys
  → Check database path in DATABASE_URL

Slow startup:
  → First build is slow (compiling wheels)
  → Subsequent builds use cached layer (fast)
  → Check /health endpoint responds in <2s

Out of disk space:
  → docker system prune -a  (removes unused images)
  → docker system df  (shows disk usage)
